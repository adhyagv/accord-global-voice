# UX Direction (Premium, Meaningful, Simulated Prototype)

## UX goals
- Make conflict-resolution progress clear, calm, and actionable.
- Show fairness and trust signals without exposing private content.
- Keep every integration explicitly labeled **simulated**.

## Experience pillars
1. **Private-by-default input flow**
   - Clear per-member privacy messaging during interviews.
2. **Transparent fairness outcomes**
   - Explain why assignments were chosen via score breakdowns.
3. **Renegotiation readiness**
   - Drift indicators make “when to revisit” obvious.

## 3D animation direction (must be meaningful)
Use lightweight, purposeful 3D scenes that communicate state, not decoration:
- **Balance sculpture:** three weighted pillars (one per roommate) visibly leveling as fairness improves.
- **Chore orbit timeline:** chore tokens orbit weekly slots; missed items wobble/fade to indicate instability.
- **Agreement lock-in transition:** once accepted, pieces snap into a stable structure signaling commitment.

Each animation must map directly to a measurable state (fairness score, completion rate, drift risk).

## Key screens (spec level)
- Private Interview Screen (member-scoped)
- Agreement Proposal Screen (shared, sanitized explanations)
- Monitoring & Drift Screen (14-day trends)
- Renegotiation Prompt Screen

## Accessibility and tone
- Calm palette, high contrast option, reduced motion mode.
- Plain-language summaries for solver output and drift reasons.
- No blame-oriented phrasing; emphasize collaborative adjustment.

## Simulated integration labeling
All UI surfaces referencing voice, notifications, calendar, or activity ingestion must display “Simulated” labels and avoid implying live third-party connectivity.
